# 無駄なもの研究所  
## Muda Mono Laboratory

> 役に立たないものを、役に立たないまま、異常な完成度で作る。

ここは、思いついた瞬間には絶対に必要なかったものを、本気で設計・実装・検収・公開するための研究所です。

効率化、生産性、課題解決、市場適合性。  
そのような立派な言葉はいったん入口へ置いてきてください。

私たちは、無駄を作ります。

---

## 研究理念

世の中には、作る前から役に立つと分かっているものがあります。

一方で、どう考えても役に立たないのに、なぜか作らずにはいられないものがあります。

本研究所が扱うのは後者です。

```text
くだらない着想
      ↓
なぜか本気で実装
      ↓
異様に完成度が上がる
      ↓
笑う
      ↓
別用途が発見される
      ↓
たまに有益なものになる（事故）
```

有益化は目的ではありません。副作用です。

---

## 無駄なもの認定基準

次のうち、3項目以上を満たすものを研究対象とします。

- 誰にも頼まれていない
- なくても一切困らない
- 説明すると「なぜ？」と聞かれる
- 制作時間と社会的価値が釣り合わない
- 技術だけは妙にしっかりしている
- 一度触ると、もう一度押したくなる
- 作っている途中で本来の目的を見失う
- 完成後に別の有益な用途が発見されてしまう
- READMEだけが壮大
- 作者がいちばん笑っている

## 研究上の重大事故

驚き屋さん構文クリエイターを作った結果、次の有益な可能性が発見されました。

- 招待ユーザー限定サイトの運用
- noteメンバーシップ向け会員特典
- 非公開プロンプトの配布回避
- AI鑑識官v5のデプロイ基盤
- Codexによるアクセス権管理
- API非依存型鑑識エンジンの検討

これは本研究所の意図した成果ではありません。

無駄なものから有益なものが発生した場合は、速やかに事故として記録します。

## コントリビューション

Issue、Pull Request、無駄な着想を歓迎します。

ただし、以下の提案は慎重に審査されます。

- 実用性を高める
- 収益性を改善する
- KPIを設定する
- ターゲットユーザーを明確にする
- 無駄をなくす

有益になりすぎた成果物は、別プロジェクトへ隔離される場合があります。
